# 다섯 언어 쓰기·기본 회화

인도네시아어, 광둥어, 네덜란드어, 폴란드어, 스웨덴어의 쓰기와 기본 회화를 10개 독립 화면으로 제공합니다. 공통 엔진과 언어별 콘텐츠의 정본은 이 저장소입니다.

- 쓰기: 글자·낱말의 획 안내, 손가락·펜·마우스 따라 쓰기, 부호를 구별하는 타이핑 연습.
- 회화: 상황별 표현과 단어, 역할 대화, 뜻 퀴즈, 간격 복습, 즐겨찾기.
- 언어별 진도·즐겨찾기·복습일을 기기에 저장하고 JSON으로 백업·복원합니다.
- 기기에 해당 언어 음성이 있을 때만 읽습니다. 광둥어를 중국어 보통화로 대체하지 않습니다.
- 한자 획 데이터는 hanzi-writer-data 2.0.1(Arphic Public License), 라틴 인쇄체 중심선은 기존 33modeling 쓰기 엔진에서 가져와 폴란드어·스웨덴어 부호를 추가했습니다.
- 인도네시아어 회화는 `travel-phrasebook/data/id.js`의 기존 원문을 가져왔습니다. 나머지 언어의 짧은 예문·설명은 직접 구성했습니다. 참고 자료는 각 화면의 학습 자료에 표시합니다.

`npm run build`로 `dist/<언어>-writing/`, `dist/<언어>-beginner/`를 만듭니다. 33modeling Pages와 로컬 Arcade는 같은 빌드 결과를 사용합니다. `npm test`, `npm run test:browser`로 데이터·저장·획 판정과 실제 화면 동작을 검증합니다.

중복된 인도네시아어 표현·단어는 하나로 보여 주고, 이전 항목 ID의 진도·즐겨찾기는 자동으로 합칩니다. 서로 다른 뜻은 합치지 않습니다. `npm run test:audit`는 다시 쓰기·지우기, 오답 복습, 검색·분류, 기존 기록 이전의 실제 화면 동작을 검사합니다.

콘텐츠는 입문용으로 직접 구성한 자료이며 원어민 전체 감수를 완료한 교재는 아닙니다. 자동 테스트는 데이터·기능의 일관성을 확인하며 번역과 발음의 언어학적 정확성을 보증하지 않습니다.
